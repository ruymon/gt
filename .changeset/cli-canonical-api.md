'gt': minor
---

Use the canonical General Translation API operations for every CLI request: branches (`listBranches`, `createBranch` with `name`/`isDefault`), uploads, file moves, file queries and downloads (`queryFiles`, `queryFilesContent`), setup (`generateProjectContext`), enqueueing (`translateFiles`), job polling (`queryJobs`), tags (`setTag`), local edits (`overwriteTranslations`), publishing, and fonts (`upsertAssets`).

Partial failures no longer stop or silently pass a run. A file, translation, move, font, local edit, or publish that the API fails to save is reported with its error, including in the end-of-run warnings summary (new "Uploads failed", "Local edits not saved", and "CDN publish failed" groups), and the run continues with the items that succeeded. Only saved files are tagged, set up, enqueued, downloaded, and published, and translations are uploaded only for saved source files. A run whose template upload fails keeps the previous `_versionId`/`_branchId` in the config. `gt save-local` does not publish a file version with a failed edit, and its final message reports failures. `gt stage`, `gt upload`, and `gt save-local` print the warnings summary like `gt translate`. The upload step's "(N moved)" count includes only succeeded moves. `gt upload` no longer reports "All files uploaded successfully" when an upload failed. `gt project status <job-id>` prints `not_found` for an unknown job. An emptied local translation is skipped with a warning instead of being sent as an edit.

When the git default branch is missing from the project, the CLI reproduces the previous branch state: it renames the project's default branch to the git default branch name, or creates that branch (promoting an existing branch of that name) as the default. When the project's default locale differs from the configured `defaultLocale`, the CLI updates it after uploading, as the previous upload route did. If the API key lacks `project:write`, the CLI warns (in the new "Project settings not updated" group) and continues with the uploaded files.
